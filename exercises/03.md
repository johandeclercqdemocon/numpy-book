# Exercises — Chapter 3

Chapter: [Views and copies](../chapters/03-views-and-copies.md) · module: [`examples/ch03_views.py`](../examples/ch03_views.py) · solutions: [03](solutions/03.md)

**1. [measure]** Make `big = np.zeros((1000, 1000))` and `small = big[:10]`. How many bytes does `small` keep alive through `small.base`? Expected: 8000000, exact.

**2. [break]** The function `center` in chapter 3 changes the column that the caller passes in. Change one line so that the caller's data stay the same, and show that they do. Expected: the original array equals its copy from before the call.

**3. [judge]** You write a public function that takes an array and returns a part of it. Does it return a view or a copy? What does a good answer weigh? (Consider memory, the caller's later writes, and what the documentation can promise.)
