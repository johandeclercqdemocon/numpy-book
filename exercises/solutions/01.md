## 1. [measure]

The strides are the number of bytes to jump along each axis. The last axis has 3 values of 4 bytes, so its stride is 4. The middle axis jumps over one row of 3 values, which is 12 bytes. The first axis jumps over 200 rows of 12 bytes, which is 2400 bytes.

```python
import numpy as np

a = np.zeros((100, 200, 3), dtype=np.float32)
print(a.strides)
print(a.nbytes)
assert a.strides == (2400, 12, 4)
assert a.nbytes == 100 * 200 * 3 * 4
```

```text
(2400, 12, 4)
240000
```

## 2. [break]

The transpose of a `(1, 5)` array is a `(5, 1)` array. An axis of length 1 is never stepped along, so its stride does not matter, and NumPy sets the contiguous flag from the other axes.

```python
import numpy as np

a = np.zeros((1, 5))
print("a   shape", a.shape, "strides", a.strides, "contiguous", a.flags.c_contiguous)
print("a.T shape", a.T.shape, "strides", a.T.strides, "contiguous", a.T.flags.c_contiguous)
assert a.T.flags.c_contiguous
assert np.shares_memory(a, a.T)
```

```text
a   shape (1, 5) strides (40, 8) contiguous True
a.T shape (5, 1) strides (8, 40) contiguous True
```

The strides changed from `(40, 8)` to `(8, 40)`, and the array is still contiguous. The flag describes the memory order that a walk follows. A walk over a `(5, 1)` array has only one axis that moves.

## 3. [judge]

**Position.** Keep the list, unless a measurement on the real service shows that the array helps.

**What a good answer weighs.** Twenty values is near the size where the fixed cost of an array call is larger than the work. The chapter measured a loss for three values. At thousands of requests each second, the cost per request matters.

The next step of the readings is the second fact. If the next step is a mean and a threshold, a list is enough. If the next step is a matrix product with a model, the model needs an array, and the conversion cost is paid once. The measurement must use the real request rate and the real next step. A benchmark of 20 values alone is not enough.

**Strongest objection.** The array gives the same code path as the offline batch job that runs on millions of readings. One code path has fewer bugs. This is an argument about maintenance and not about speed.

**What overturns the position.** A profile can show that the conversion costs less than 5 percent of the request time. A requirement to share code with the batch job has the same effect.
