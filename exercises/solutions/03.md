## 1. [measure]

```python
import numpy as np

big = np.zeros((1000, 1000))
small = big[:10]
print("small owns:", small.nbytes, "bytes")
print("small keeps:", small.base.nbytes, "bytes alive")
assert small.base.nbytes == 8_000_000
assert small.nbytes == 80_000
```

```text
small owns: 80000 bytes
small keeps: 8000000 bytes alive
```

The slice has 10 rows of 1000 values of 8 bytes, which is 80,000 bytes. The base has 1000 rows, which is 8,000,000 bytes. The ratio is 100.

## 2. [break]

Replace `x -= x.mean()` with `x = x - x.mean()`. The second form makes a new array and binds the name `x` to it. The array of the caller is not touched.

```python
import numpy as np


def center(x):
    x = x - x.mean()
    return x


data = np.array([[1.0, 10.0], [3.0, 20.0], [5.0, 30.0]])
before = data.copy()
centered = center(data[:, 0])
print("data unchanged:", np.array_equal(data, before))
print("result:", centered)
assert np.array_equal(data, before)
```

```text
data unchanged: True
result: [-2.  0.  2.]
```

## 3. [judge]

**Position.** Return a view when the function is a selection that the caller keeps in step with the original. Return a copy when the function computes something. Write the choice in the first line of the docstring.

**What a good answer weighs.** A view costs nothing and keeps the base alive, which can be a large block. A copy costs memory and time and breaks the link. A later write by the caller does not change the original.

The danger of a view is a write that the caller does not expect. The danger of a copy is a write that the caller expects and does not get. NumPy returns views for slices and copies for index lists, so a caller who knows NumPy expects the same pattern.

**Strongest objection.** A function that returns a view or a copy depending on the input, like `reshape`, is a trap. It is better to always copy. This is correct for a public function. The cost is memory on large arrays, and the answer is to document the exception where the cost is measured.

**What overturns the position.** A user report of a lost write or an unexpected change shows that callers do not read the docstring. Then return copies, and add a separate function that returns a view.
