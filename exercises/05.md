# Exercises — Chapter 5

Chapter: [Broadcasting](../chapters/05-broadcasting.md) · module: [`examples/ch05_broadcasting.py`](../examples/ch05_broadcasting.py) · solutions: [05](solutions/05.md)

**1. [measure]** Use `tracemalloc` to measure the peak memory of `dist_broadcast` for two sets of 1000 points in 32 dimensions. Expected: 264 MB, within ±10 percent. State the number of values in the temporary array and the result of the arithmetic.

**2. [break]** Make `dist_dot` return a maximum error larger than 1.0 for `float64` points that lie in a cube of side 1. Change only the position of the cube. Expected: an offset of 1e8 gives an error of about 4. Explain the result with the gap between neighbor `float64` values.

**3. [judge]** Your service computes distances for 50 points against 50,000 points in 128 dimensions, in `float32`, on a machine with 8 GB. Which of the three versions do you ship? What does a good answer weigh? (Consider the size of the temporary array, the precision, and whether centering is possible when the second set changes at each call.)
